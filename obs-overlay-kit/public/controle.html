    Chat en direct commentaires YouTube et Facebook

    YouTube
    Obtenir une clé API YouTube (gratuit, 5 minutes)
    1. Allez sur console.cloud.google.com avec votre compte Google et créez un projet (ex. « Overlays »).
    2. Menu API et services › Bibliothèque : cherchez YouTube Data API v3 et cliquez sur Activer.
    3. Menu API et services › Identifiants › Créer des identifiants › Clé API. Copiez la clé (elle commence par « AIza »).
    4. Conseillé : cliquez sur la clé › Restreindre la clé › API : YouTube Data API v3.
    5. Collez la clé ici avec l'adresse du direct (il doit être en cours, public ou non répertorié, chat activé), puis Connecter.

    Le quota gratuit (10 000 unités/jour) permet environ 5 à 6 heures de direct par jour avec une lecture toutes les 5 secondes.

    Facebook
    Obtenir un jeton Facebook (direct publié depuis une Page)
    1. Le direct doit être diffusé sur une Page Facebook dont vous êtes administrateur (les profils personnels ne sont pas accessibles par l'API).
    2. Allez sur developers.facebook.com › Mes applications › Créer une application (type « Autre » › « Entreprise »).
    3. Ouvrez l'Explorateur de l'API Graph (menu Outils). Choisissez votre application, puis dans « Utilisateur ou Page », votre Page.
    4. Ajoutez les autorisations pages_read_engagement et pages_read_user_content, cliquez sur Generate Access Token et acceptez.
    5. Copiez le jeton (il commence par « EAA ») et collez-le ici avec l'adresse de la vidéo en direct, puis Connecter.

    Ce jeton expire au bout de quelques heures. Pour un jeton durable, utilisez l'Outil de débogage des jetons d'accès › « Prolonger le jeton d'accès », puis régénérez le jeton de Page.
